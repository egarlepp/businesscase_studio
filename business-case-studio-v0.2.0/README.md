# Business Case Studio

A React + TypeScript MVP for modeling the ROI, TCO, risk, and realized value of internally developed applications, including AI-assisted and vibe-coded solutions.

## Included modules

- Executive overview with ROI, TCO, NPV, payback, benefit-cost ratio, confidence, and warnings
- Application profile and organizational scope
- Productivity, management, reconciliation, capacity, workforce, revenue, and risk calculators
- Build, run, change, governance, security, and technical-debt TCO
- AI token economics, human oversight, traditional-build comparison, and time-to-market value
- Technical-health scoring across ten maintainability dimensions
- Conservative, expected, and upside scenarios
- Assumption register with confidence and approval status
- Actuals versus forecast and benefit realization
- Executive report summary and JSON export

## Run

```bash
npm install
npm run dev
```

## Validate

```bash
npm test
npm run build
node verify-calculations.mjs
```

The default numbers are illustrative and should be replaced with approved assumptions and evidence.
